# Michael's Foundations Design Philosophy
> This document defines the design principles that guide every Foundation project. Its 
> purpose is to ensure that every page, interaction, and visual element contributes 
> to a consistent, learner-centered experience.

## Core Principles

### Rule #1
> Protect the Consistency.
> Once users learn how your site behaves, don't surprise them.

---

### Rule #2
> **Everything communicates**

- Every color...
- Every font...
- Every amount of spacing...
- Every animation...

> ...teaches the learner something. Nothing exists just because it looks cool.

--- 

### Rule #3
> **Motion should have meaning**

> Motion exists to:
- guide attention,
- communicate interaction,
- reinforce purpose,

> not simply because animation is possible.

### Rule #4
> **Shared DNA, Unique Personality**
- Reusable components share the same design language.
- Each component has its own purpose and interaction style.
---

### Rule #5
> **Design Before Code**

Always answer:
- What problem are we solving?
- What should the learner experience?
- How does this fit the design system?

> Only then write HTML/CSS.

---

### Rule #6 One Change - One Test
> **Never invite Mr. Frankenstein.**

- Small changes
- Immediate testing
- Then continue

---

### Rule 7
> **Build for Future Michael**
> Write code that you'll be happy to read six months from now.

---

### Rule 8
> **Explain the Why**

- Code tells the browser what to do
- Documentation tells future developers why

---

## Section Philosophy
### Hero
#### Purpose
> **Inspire confidence**

#### Behavior
- Almost no animation
- Calm
- Inviting

#### Design Intent
> The hero establishes trust before asking the learner to do anything. It sets a calm, 
> confident tone for everything that follows.

---

### Learning Pillars
#### Purpose:
> **Explore subjects**

#### Behavior:
> **Cards feel approachable**
- Not exciting...
- Not distracting...
- Just inviting.

---

### Learning Paths
#### Purpose:
> **Make a decision**

#### Behavior:
- Card moves.
- Shadow appears.
- Link nudges forward.

> The page is quietly saying, "Go ahead...choose."

### Journey
#### Purpose:
> **Inspire the future**

#### Behavior:
- Richest animation.
- Icon grows.
- Title responds.
- Card lifts.

> It communicates growth.

--- 

### Design Intent
> This section encourages learners to take action. The subtle movement, shadow, and 
> call-to-action animation communicate that each learning path is interactive without 
> overwhelming the user.

---

### Learning Requires Participation
- Reading alone builds familiarity.
- Speaking builds confidence.
- Using the language builds proficiency.
