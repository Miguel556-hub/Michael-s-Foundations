# Conversation Laboratory — Single Authoritative Testing Lab

Open `index.html` with VS Code Live Server. The Conversation Gallery is the entry point.
Select any of the seven scenarios to open its individual conversation experience.
Use **Back to Conversation Gallery** to choose another scenario.

## Files
- `index.html` — Gallery and conversation interface
- `styles.css` — All presentation and gallery styles
- `app.js` — Shared conversation, speaking, listening, help, and navigation
- `conversations.js` — All seven scripts, possible answers, meanings, and visual discoveries
- `avatar-registry.js` — Seven avatar records and image paths
- `*-portrait.png` — Seven portrait images

## Notes
- Anna's original portrait is preserved.
- Six other portraits are first-pass crops from a generated visual concept; review them before final approval.
- The six new scripts come from the earlier six-avatar prototype. Anna's script is adapted from the existing working Anna laboratory.
- This is a self-contained TESTING LAB, not integrated into Family Relationships.
- Voice depends on browser Russian speech synthesis and microphone recognition support.
- The response engine recognizes scripted responses and some natural variations, not unlimited free conversation.
- All code files are readable, not minified.
